# Student Project Showcase & Peer Review Platform

A web-based platform for students to **showcase their academic projects** and receive **faculty feedback and reviews**.

### Features

* Student registration and login
* Add and showcase projects
* Upload project documents and images
* Faculty project review and feedback
* Admin user and project management

### Technologies

* **Frontend:** JSP, HTML, CSS, JavaScript
* **Backend:** Java, Spring Boot
* **Database:** MySQL
* **Tools:** Maven, Git & GitHub

### Project Workflow

`Student → Submit Project → Faculty Review → Feedback → Improvement`

### Purpose

To provide a centralized platform for managing, showcasing, and reviewing student projects.
